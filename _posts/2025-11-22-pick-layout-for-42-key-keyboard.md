จากแต่ก่อนใช้คีบอร์ด 108 ปุ่ม ปัจจุบันเหลือ 66 ปุ่มโดยการใช้ alice layout มาได้ 3-4 ปีแล้ว ตอนนี้อยากจะลองลดลงอีกเหลือ 42 ปุ่มดู โดยตัวที่เลือกมาคือ [Corne keyboard](https://github.com/foostan/crkbd) ซึ่งต้องปรับตัวกับ layout ใหม่ แต่จะใช้ layout แบบไหนดีล่ะ

ตอนนี้ยังตัดสินใจเลือกระหว่าง 2 layout ไม่ได้

## Layout 1 - Simple
คอนเซปคือ ปุ่มต้องง่าย  ไม่มีการใช้ tab dance หรืออะไรทั้งนั้นทำให้การใช้งานไม่ซับซ้อนแต่ต้องง่าย layout ทุกอย่างยังคล้ายเดิม โดยหลังจากใช้ไปสักพัก ที่ยังปรับตัวไม่ได้คือปุ่ม ESC ที่ไม่ได้อยู่ layer แรกกับ shift ด้านซ้ายขวา ที่ดันไม่ตรงกันทำนิ้วก้อยรวน

![Layout 1 - Simple](/assets/images/post/pick-layout-for-42-key-keyboard/layout01.svg)

## Layout 2 - Manoonchai 
ปรากฏว่าไอ้ layout แรกติดปัญหาพิมพ์ไทยไม่ได้เลย เพราะไทยจะมีบางตัวอักษรอยู่แถวตัวเลข เลยเปลี่ยนไปใช้ตัวอักษรไม่อยู่แถวตัวเลขแบบ [Manoonchai](https://manoonchai.com/) แต่ติดปัญหาว่า ไม้ไต่คู้ มันโดนเอาไปซ่อนใน symbol เลยพยายามจับใหม่ได้ layout แบบนี้ ปรากฏว่าตอนนี้ยังใช้ backspace กับ tab ยังไม่คล่อง ใช้ Manoonchai ก็ยังไม่ได้ คงต้องปรับตัวอีกสักพักใหญ่

![Layout 2 - Simple](/assets/images/post/pick-layout-for-42-key-keyboard/layout01.svg)


## แล้วใช้แบบไหน
ตอนนี้ยังตกลงใจไม่ได้ว่าจะใช้แบบไหนดี คงต้องสลับไปสลับมาสักพัก ถ้าเลือกได้แล้วเดี๋ยวมาลงอัปเดตอีกที
